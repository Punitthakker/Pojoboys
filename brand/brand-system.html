Rules

  • Clear space around the mark: the height of the brace's top arm, all sides. Minimum size: mark 12 mm print / 32 px screen; lockup 40 mm / 120 px.
  • Colour version only on black. On any other background use mono. Never outline, never add shadows, never rotate the smooth mark (the crest may spin).
  • The block variant is for big surfaces only (tee back, hero, posters). Never below 60 mm.
  • Embroidery: use the mono files. Max 2 threads: white, plus Kit Orange for the bowl.

  • Black first. Every surface starts black; Chalk is the default ink.
  • Kit Orange is a signal, not a theme: one element per composition (the bowl, a CTA, a label). Never more than ~10% of a surface. Never orange text on white.
  • Ash for secondary text only. Panel and Line are the only greys allowed for structure.
  • Thread refs: Chalk = Madeira Classic 40 #1001 / Isacord 0015. Kit Orange = Madeira 1278 / Isacord 1306.

Typography

Display: Unbounded 800/900 (Google Fonts). Headlines, wordmark, numbers. Tight tracking (-0.01em), sentence case for headlines, all-caps only in the wordmark.

Body: Inter 400/600 (Google Fonts). Everything else. Labels in 600, uppercase, +0.14em tracking, 11-12 px.

Code moments: the system monospace stack. No third webfont.

Voice

Short. Playful. Confident. Kid-safe. Speak like a coach who codes.
